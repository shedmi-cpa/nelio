# Nelio

מערכת לאיסוף מסמכים חודשי למשרד רואי חשבון. כל לקוח מקבל קישור אישי ומעלה מהטלפון, הקבצים נשמרים לבד בתיקייה הנכונה, והמשרד רואה במסך אחד מה חסר.

**פרויקט הדגמה.** המשרד, "שדמי ושות', רואי חשבון", בדיוני, וכל הנתונים במערכת מומצאים.

## מה יש כאן

| תיקייה | מה יש בה |
|---|---|
| `docs/` | הדף של הלקוח. GitHub Pages מפרסם אותו בכתובת https://shedmi-cpa.github.io/nelio/ |
| `apps-script/` | השרת: קוד Google Apps Script שמחובר לגיליון של המשרד |

## איך זה עובד

הדף שולח את הקובץ לשרת ב-Apps Script. השרת בודק את הקישור האישי, שומר את הקובץ ב-Google Drive ורושם אותו ב-Google Sheets.

## מצב

בבנייה. שלב 3.1: השלד, העלאה מקצה לקצה.
