# מסמכי הדמו של Nelio

הענף הזה מכיל רק מסמכים לדוגמה: קובץ לכל העלאה של משרד הדמו "שדמי ושות', רואי חשבון". הקוד של המערכת נמצא בענף `main`.

- **הכול בדוי:** כל מסמך מסומן "לדוגמה". השמות בדויים, וכל המספרים מוסתרים באמצע (`XXXX-1234`).
- **מאיפה הם באים:** הקוד `demo/render_docs.py` בענף `main` מצייר אותם מתוך `demo/seed.json`. בקובץ `manifest.json` רשום ה-`seed_id` שממנו נוצרו, וטביעת אצבע לכל קובץ.
- **מי קורא אותם:** הפונקציה `seedDemoFiles` בשרת (`apps-script/Seed.gs`) יוצרת מהם את הקבצים ב-Drive של המשרד.
- **הנתיב** הוא השדה `asset` של ההעלאה: `C07/2026-10/BANK_STATEMENT_02.jpg` = לקוח C07, בקשה של אוקטובר 2026, דף בנק, הקובץ השני.
