# Nelio

מערכת לאיסוף מסמכים חודשי למשרד רואי חשבון. כל לקוח מקבל קישור אישי ומעלה מהטלפון, הקבצים נשמרים לבד בתיקייה הנכונה, והמשרד רואה במסך אחד מה חסר.

**פרויקט הדגמה.** המשרד, "שדמי ושות', רואי חשבון", בדיוני, וכל הנתונים במערכת מומצאים.

## מה יש כאן

| תיקייה | מה יש בה |
|---|---|
| `docs/` | הדף של הלקוח. GitHub Pages מפרסם אותו בכתובת https://shedmi-cpa.github.io/nelio/ |
| `apps-script/` | השרת: קוד Google Apps Script שמחובר לגיליון של המשרד |
| `.github/workflows/` | ההעלאה האוטומטית של השרת |

## איך זה עובד

הדף שולח את הקובץ לשרת ב-Apps Script. השרת בודק את הקישור האישי, שומר את הקובץ ב-Google Drive ורושם אותו ב-Google Sheets.

## איך קוד עולה לאוויר

כל שינוי בענף `main` עולה לאוויר לבד:

- **הדף:** שינוי ב-`docs/` מתפרסם ב-GitHub Pages תוך כדקה.
- **השרת:** שינוי ב-`apps-script/` מפעיל את `deploy-server.yml`. הוא מעלה את הקוד עם [clasp](https://github.com/google/clasp), פורס גרסה חדשה באותה כתובת, ובודק שהשרת עונה עם מספר הגרסה החדש.

ההתחברות של clasp לחשבון הגוגל של המשרד שמורה בסוד `CLASPRC_JSON` של המאגר, ולא בקוד. את הקוד לא עורכים בעורך של Apps Script, כי ההעלאה הבאה מחליפה את כל מה שיש שם.

## מצב

בבנייה. שלב 3.2: ניסיונות שבירה, והכרעות על שמות התיקיות והקבצים ב-Drive.
