# קבצי המותג של שדמי ושות', רואי חשבון

כל האותיות הומרו לצורות, ולכן הקבצים לא תלויים בשום גופן. הצבעים והכללים: `rules.md` בפרויקט (D38).

| קובץ | שימוש |
|---|---|
| `logo.svg` | הלוגו הראשי: "שדמי" ב-Bellefair, ומתחתיו "ושות', רואי חשבון" |
| `mark-circle.svg` | הסימן המשני: ש בעיגול דק. גם לחותמת "התקבל הכול" |
| `mark-circle-email.png` | הסימן המשני לחתימת המייל, ברוחב 184 פיקסלים (מוצג ב-46 פיקסלים, בחדות כפולה פי ארבעה), על רקע לבן |
| `favicon.svg`, `favicon.ico`, `favicon-32.png` | אייקון הדפדפן: ש בהירה על ריבוע בים עמוק |

הקבצים נוצרים בקוד: `tools/make_brand.py`. הגופנים (Bellefair ו-Assistant) הם בקוד פתוח, ברישיון OFL.
