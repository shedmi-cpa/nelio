# משרד הדמו

כל הנתונים כאן בדויים: המשרד "שדמי ושות', רואי חשבון", 60 הלקוחות שלו, אנשי הקשר והמסמכים.

| קובץ | מה הוא עושה |
|---|---|
| `generate_seed.py` | בונה את המשרד: לקוחות, מחזורי אוגוסט וספטמבר 2026 (סגורים) ומחזור אוקטובר עד יום שני 9/11/2026 בערב. הקוד מדמה כל לקוח: מתי הוא מעלה, מה הוא שוכח, מה יוצא מטושטש, ומתי המשרד בודק. |
| `seed.json` | התוצאה. הפונקציה `seedDemo` בשרת קוראת אותו, כותבת אותו לגיליון ויוצרת את הקבצים ב-Drive. |
| `render_docs.py` | מצייר קובץ לכל אחת מ-1,025 ההעלאות ב-`seed.json`: דפי בנק, פירוטי אשראי, דוחות Z, חשבוניות, קבלות, קבלות דלק, דוחות שעות ומכתבים. "הורדה" יוצאת PDF, ו"צילום" יוצא תמונה מהטלפון: שולחן, זווית, צל ותאורה לא אחידה. |
| `fonts/` | רשימת הגופנים של המסמכים (Heebo, Assistant, Frank Ruhl Libre ו-Miriam Libre, ברישיון SIL OFL). `npm install` בתיקייה מוריד אותם. |

- **אותן תוצאות בכל הרצה:** המחולל משתמש במספר אקראי קבוע. `python3 demo/generate_seed.py`
- **בלי סודות:** אין כאן טוקנים או כתובות מייל. השרת יוצר אותם בזמן ההקמה.
- **לוח השנה:** בלי פעילות בשבת ובחג, וההודעות יוצאות רק בשעות המותרות. המחולל בודק את זה בעצמו לפני שהוא כותב את הקובץ.
- **המסמכים:** קובץ לכל העלאה, בענף `demo-assets`, באותו נתיב כמו השדה `asset` (למשל `C07/2026-10/BANK_STATEMENT_02.jpg`).
  - **כל מסמך מסומן "לדוגמה",** וכל המספרים מוסתרים באמצע (`XXXX-1234`). הקוד בודק את שניהם לפני שהוא מצייר, ועוצר אם משהו חסר.
  - **השמות בדויים:** הבנק, חברות האשראי, רשת הדלק והספקים נבדקו בחיפוש. העסקים שמופיעים כלקוחות בחשבוניות הם לקוחות אחרים של משרד הדמו.
  - **תמונה "מטושטשת"** נראית כמו הסיבה שהמשרד כתב כשדחה אותה: מטושטשת, חשוכה, או חתוכה בלי הסכום.
  - **אותם קבצים בכל הרצה,** בית אחר בית. ב-PDF כתוב זמן ההעלאה המדומה, ולא הזמן שבו צויר.
- **איך מייצרים מחדש:**
  ```
  cd demo/fonts && npm install && cd ../..
  pip install playwright pillow numpy
  python3 demo/render_docs.py --out ../demo-assets            # כל המסמכים, כ-4 דקות
  python3 demo/render_docs.py --out /tmp/x --only C07 --limit 5  # מדגם
  ```
  הקוד משתמש בכרום שמותקן במחשב (`/usr/bin/google-chrome`, או במשתנה `CHROME`). שינוי ב-`seed.json` מחייב לצייר מחדש ולהעלות מחדש לענף.
